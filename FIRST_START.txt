처음 시작하기

1. ZIP 압축을 풉니다.
2. Windows PC에 Python 3.11 이상과 FFmpeg를 설치합니다.
3. START_WINDOWS.bat를 더블클릭합니다.
4. 관리 화면에서 화면 샘플을 재생합니다.
5. README_KO.md 안내대로 API 키 2개와 OAuth 파일을 준비합니다.
6. 본인 유튜브 채널로 최초 로그인합니다.
7. 오늘 영상 제작 → 내용 검토 → 업로드 순서로 비공개 테스트합니다.

이 버전은 후보 50개를 조사하고 하루 3개를 만드는 기본 설정입니다.
전체 유튜브 조회수 TOP 50 전수조사가 아닙니다.
샘플은 자막과 배경음악이 있는 화면 미리보기이며 내레이션은 없습니다.
실제 제작 영상의 내레이션은 API 키 연결 후 생성됩니다.
API 비용은 별도이고 채널 로그인 전에는 실제 업로드되지 않습니다.

완전 자동 예약 게시:
config.json의 mode를 scheduled로, require_review를 false로 설정합니다.
python app.py daemon을 계속 실행하거나 작업 스케줄러에 매일 실행을 등록합니다.
PC 또는 서버가 켜져 있어야 합니다.

구매 전환 연결:
상품 태그·관련 영상·채널 프로필 링크는 유튜브 스튜디오에서 연결합니다.
조회수는 프로그램이 가져오며 상품 클릭·구매·수익·비용은 수동 기록합니다.

직접 촬영한 제품 자료가 없으면 구매 체크리스트 카드 영상을 생성합니다.
실제 제품 비교는 사용 권리가 있는 촬영 자료와 확인된 사실을 추가하세요.
수익과 조회수, 수익화 승인은 보장되지 않습니다.
